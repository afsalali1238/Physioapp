# Legacy Planning Archive — 2026-08-26

These files are preserved, not deleted. They describe the earlier separate, 2D-first Anatomy
Explorer plan and its parallel module assignments. The product later became one unified 3D-first
anatomy and exercise application.

Useful material remains inside: early acceptance criteria, file-boundary ideas, safety thinking,
validation concepts, and module decomposition. However, the archived files contain superseded
requirements such as symptom questions, 3D as a late optional wave, and a separate-app handoff.

Do not execute prompts or module briefs from this folder directly. Use the active root documents,
especially `PRD.md`, `HANDOFF.md`, and `BUILD-PLAN.md`, and selectively carry forward compatible
implementation detail when the new backlog is written.
