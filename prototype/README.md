# Prototypes

Standalone HTML, no build step. Open directly in a browser.

| File | What it is |
|---|---|
| `patient-library-prototype.html` | The UI prototype with sample neck content. This is the design reference for modules M06–M11. Published for review at the artifact link in `memory.md`. |
| `physiotherapist-brief-form.html` | The 16-question discovery form sent to the physiotherapist. Kept for the record. |

These are **not** the application. They are single-file references that the Astro build in `src/` should reproduce. When the prototype and the built app disagree, `docs/DESIGN-SYSTEM.md` is authoritative.
